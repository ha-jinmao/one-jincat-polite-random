# 近猫礼貌随机 (JinCat Polite Random)

> 一坨屎一样的随机数取值工具，心情不好还会骂你。

## 📖 这是什么？
这是一个用 Python 写的命令行随机数生成器。
它跟普通的随机数生成器不一样——它脾气不太好，但对盲人很有爱心。

## ✨ 核心功能
- **支持整数与小数**：整数会问你要不要包含边界，小数则直接生成。
- **盲人关怀协议**：当你把最大值和最小值输反了，它会帮你倒过来，并温柔地说“关爱盲人，温暖同行”。
- **五阶认知容错**：如果你连“是”和“否”都分不清，它会给你 5 次机会。如果你 5 次都错，它就会用“拼多多提现”级别的概率嘲讽你，然后让你滚。
- **整局重开**：支持“再来一次”，让你从“选整数还是小数”开始重新做人。

1. 确保电脑装了 Python。
2. 打开命令行（cmd），进入该文件夹。
3. 输入：
   ```bash
   python a=0.py
